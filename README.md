# 회귀챗 (Regression Chat)

선형회귀 · 비선형회귀 · 인공신경망을 **한 번에 학습**해 두고, 문장으로 질문하면 답하는 대화형 모델입니다.

기존 두 저장소의 코드와 데이터를 그대로 사용했습니다.

| 가져온 곳 | 내용 |
|---|---|
| [`-1`](https://github.com/baekjiwoong5/-1) `regression.py` | 선형회귀, 2차 다항회귀, 비선형회귀(거듭제곱·지수), 키·몸무게 199명 |
| [`-2`](https://github.com/baekjiwoong5/-2) `ann_diabetes_predictor.py` | NumPy 인공신경망(순전파·역전파·Adam·조기 종료), 당뇨병 442명 |

> **LLM이 아닙니다.** 수치 데이터 641행으로는 대형 언어 모델을 학습시킬 수 없습니다.
> 이 프로그램은 질문 문장에서 열 이름과 숫자를 찾는 **규칙 기반** 방식으로 말을 이해하고,
> 답은 학습된 회귀·신경망 모델이 계산합니다. 불러온 데이터에 관한 질문에만 답합니다.

## 파이썬으로 실행

```bash
git clone https://github.com/baekjiwoong5/LLM.git
cd LLM
pip install -r requirements.txt

python chat.py                           # data/ 폴더의 모든 데이터를 학습하고 대화 시작
python chat.py -q "키 175면 몸무게는?"    # 질문 하나만 하고 종료
```

```
질문> 키 175면 몸무게는?
[키·몸무게] 키 175cm → 예측 몸무게
  선형회귀            70.0 kg
  비선형(2차 다항)      69.3 kg
  비선형(거듭제곱)       69.5 kg
  비선형(지수)         69.2 kg
  인공신경망           69.0 kg  ← 검증 오차 최소
→ 약 69.0 kg (이 모델의 테스트 오차 RMSE 11.9 kg)

질문> BMI 30이고 혈압 110인 환자의 진행도
[당뇨병 진행도] BMI 30, 평균 혈압 110 → 예측 질병 진행도
  선형회귀              204.6
  비선형(2차 다항)        175.9  ← 검증 오차 최소
  ...
입력하지 않은 값은 데이터 평균(값이 두 종류뿐인 열은 더 많은 쪽)으로 채웠습니다: 나이 48.52, 성별 1, ...
```

### 물어볼 수 있는 것

| 질문 예 | 답 |
|---|---|
| `키 175면 몸무게는?` / `175` | 다섯 모델의 예측값 |
| `나이 59, 성별 2, bmi 32.1, 혈압 101 … 진행도는?` | 일부 값만 줘도 예측 (나머지는 평균으로 채움) |
| `59 2 32.1 101 157 93.2 38 4 4.8598 87` | 열 순서대로 숫자만 줘도 예측 |
| `어떤 모델이 제일 정확해?` / `당뇨 성능 비교` | 테스트 데이터 MAE · RMSE · R² 표 |
| `회귀식 알려줘` / `신경망 구조는?` / `2차 다항 식` | 학습된 식과 계수, 신경망 구조 |
| `bmi 평균은?` / `키 범위` | 평균 · 표준편차 · 범위 |
| `어떤 데이터가 있어?` | 불러온 데이터와 열 목록 |
| `/load 파일.csv [목표열]` | 다른 표 데이터를 불러와 바로 학습 |

키·몸무게용, 당뇨병용으로 프로그램이 나뉘지 않습니다. 질문에 나온 열 이름을 보고 어느 데이터에 관한 질문인지 스스로 고릅니다.

## 다른 데이터에 쓰기

숫자 열이 있는 표(csv, xlsx)면 됩니다. 열 개수와 이름은 상관없습니다.

```bash
python chat.py --data 내자료.csv --target 예측할열이름
```

- 숫자가 아닌 열과 빈 값이 있는 행은 자동으로 빼고, 무엇을 뺐는지 알려줍니다.
- `--target`을 생략하면 마지막 숫자 열을 예측합니다.
- 열 이름이 `키 (cm)`처럼 괄호 단위를 달고 있으면 이름(`키`)과 단위(`cm`)로 나눠 씁니다.
- 열 이름에 별명을 붙이려면 같은 폴더에 `내자료.aliases.json`을 둡니다. ([`data/diabetes.aliases.json`](data/diabetes.aliases.json) 참고)
- 데이터에 맞지 않는 모델(예: 0 이하 값이 있을 때의 거듭제곱 모델)은 건너뛰고 나머지로 진행합니다.

## 학습 방식

`models.py`의 `fit_all()` 한 번 호출로 다섯 모델이 **같은 학습 데이터**로 학습되고 **같은 테스트 데이터**로 평가됩니다.

| 계열 | 모델 | 식 | 푸는 방법 |
|---|---|---|---|
| 선형 | 선형회귀 | y = b₀ + Σ bᵢ·xᵢ | 최소제곱법 |
| 비선형 | 2차 다항 | y = c₀ + Σ (cᵢ·xᵢ + dᵢ·xᵢ²) | 최소제곱법 |
| 비선형 | 거듭제곱 | y = a · Π xᵢ^bᵢ | `scipy.optimize.curve_fit`, 초기값은 로그 직선의 계수 |
| 비선형 | 지수 | y = a · e^(Σ bᵢ·xᵢ) | `scipy.optimize.curve_fit`, 초기값은 로그 직선의 계수 |
| 인공신경망 | MLP | 입력 → 32 (ReLU) → 16 (ReLU) → 1 | NumPy 순전파 · 역전파 · Adam · 조기 종료 |

- 분할은 학습 70% / 검증 15% / 테스트 15%, 시드 42. `-2` 저장소의 `train_test_split`과 같은 행이 뽑히도록 맞췄습니다.
- 예측의 대표값은 **검증 오차가 가장 작은 모델**로 정합니다. 테스트 데이터는 성능 보고에만 씁니다.
- 기존 식은 입력이 하나(키)였는데, 입력이 여러 개여도 되도록 넓혔습니다. 2차 다항은 열끼리의 곱(교차항)은 넣지 않았습니다.

## 결과

### 당뇨병 진행도 (테스트 67명)

| 모델 | MAE | RMSE | R² |
|---|---:|---:|---:|
| 평균값 예측 (기준선) | 66.45 | 75.54 | −0.005 |
| 선형회귀 | 45.57 | 56.03 | 0.447 |
| 비선형 (2차 다항) | 43.90 | 55.47 | 0.458 |
| 비선형 (거듭제곱) | 46.21 | 57.19 | 0.424 |
| 비선형 (지수) | 45.24 | 55.56 | 0.456 |
| 인공신경망 | 43.69 | 53.19 | 0.502 |

선형회귀와 인공신경망의 숫자는 `-2` 저장소 README의 결과와 같습니다 (신경망도 63 에폭 중 13 에폭의 가중치).
테스트에서는 인공신경망이 가장 좋지만, 검증 오차는 2차 다항이 가장 작아 대표값으로는 2차 다항이 선택됩니다.

### 키·몸무게 (테스트 30명)

| 모델 | MAE (kg) | RMSE (kg) | R² |
|---|---:|---:|---:|
| 평균값 예측 (기준선) | 12.20 | 16.82 | −0.113 |
| 선형회귀 | 7.85 | 11.68 | 0.463 |
| 비선형 (2차 다항) | 7.81 | 11.69 | 0.462 |
| 비선형 (거듭제곱) | 7.81 | 11.68 | 0.463 |
| 비선형 (지수) | 7.83 | 11.71 | 0.460 |
| 인공신경망 | 8.03 | 11.88 | 0.445 |

다섯 모델의 차이가 0.2 kg 이내라 사실상 같습니다.
`-1` 저장소는 199명 전체로 학습하고 같은 199명으로 평가해서 RMSE가 8.48 kg이었고, 여기서는 139명으로 학습해 처음 보는 30명으로 평가하므로 숫자가 다릅니다. 같은 코드에 199명 전체를 넣으면 `-1`의 식(y = −130.75 + 1.1492·x 등)이 그대로 나옵니다.

## 한계

- 말을 이해하는 부분은 규칙 기반이라, 열 이름(또는 별명)이 들어가지 않은 질문은 알아듣지 못합니다.
- 입력 → 목표 방향으로만 예측합니다 (`몸무게 70이면 키는?`에는 답하지 않습니다).
- 값을 일부만 주면 나머지는 평균으로 채우는데, 실제로는 함께 움직이는 값들(예: 총콜레스테롤과 LDL)이라 예측이 부정확해질 수 있습니다.
- 학습 데이터 범위 밖의 값은 경고와 함께 답하지만 믿기 어렵습니다.
- 학습용 과제이며 의료적 판단에 쓸 수 없습니다.
